# ML_project
In this project I was testing supervised Machine Learning (ML) algorithms for weather condistions prediction.  
I've tried to run K-nearest neighbors (KNN), Decision Tree (DT) and Artificial Neuronal Network (ANN) methods.
In the second part of the project I was testing algorithms like: hierarchical clustering, random forest, deep learning methods (Convolutional Neuronal Networks - CNNs, Reccurent Neuronal Networks - RNNs) and Generative Adversarial Networks(GANs).

This repository contains data and Jupyter Notebooks used to prepare and use the weather data for machine learning methods.  
Additionally, I include all the data from this exercise plus the final [presentation - Part1](Others/Exercise_1.6_Presentation_JKG.pdf) and final [presentation - Part2](Others/Exercise_2.6_Presentation_JKG.pdf).
Some more details about the data origin, as well as the results and summary, can be found in the presentation - Part1.  
Presentation - Part2 showcases three thought experiments in which ML methods are used to predict the weather in Europe.
